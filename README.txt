САЙТ БОЙЦОВСКОГО КЛУБА «ВЕРШИНА»
================================

Состав
  index.html        — весь сайт (одна страница)
  assets/logo.png   — логотип
  assets/img/       — фотографии

Как посмотреть
  Распакуйте архив и откройте index.html в браузере (нужен интернет —
  шрифты и анимации подгружаются с CDN).

Как выложить в интернет (любой вариант)
  • Netlify Drop: зайдите на app.netlify.com/drop и перетащите папку сайта — получите ссылку за минуту.
  • Любой хостинг (Timeweb, Beget, REG.RU и т.п.): загрузите содержимое папки в корень сайта (public_html).
  • GitHub Pages / Vercel — тоже подходят, сайт статический.
  После подключения домена замените в index.html строку
    <meta property="og:image" content="assets/img/team.jpg">
  на полный адрес, например https://вершина-клуб.рф/assets/img/team.jpg — тогда в мессенджерах появится превью.

Что менять самостоятельно (в index.html, блок <script> внизу)
  CONFIG    — номер WhatsApp, Instagram, телефон, ссылки Telegram и VK.
              Пока ссылка Telegram/VK равна '#', кнопка на сайте скрыта.
  SCHEDULE  — расписание групп: название, возраст, уровень, дни и время.

Фото из Instagram
  Папка «Фото из Instagram» — все снимки, доступные без входа в аккаунт:
  клуб, Денис, Антон. В каждой папке есть «подписи.txt» с датой, ссылкой и текстом поста.
  Обновить выгрузку: python tools/ig_fetch_all.py (новые посты дописываются в список в начале скрипта).
  Эта папка в архив сайта не входит — на сайт идут только файлы из assets/.

Фото тренеров
  Положите фото в assets/img/ и вставьте внутрь блока <div class="coach-img"> строку
    <img src="assets/img/coach-denis.jpg" alt="Денис Владимирович">
